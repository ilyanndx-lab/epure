# Modules existants dans cette instance Épure

- **admin** (Admin) — Organisation et classement automatique des fiches PDF
- **chat** (Chat) — Conversation multi-modèles avec orchestration et recherche web
- **clicker** (Clicker) — Module de clicker avec compteur
- **code** (Code) — Agent de code multi-langages avec exécution et vérification
- **dinosaure** (Dinosaure) — Un jeu de dinosaure rétro amélioré avec score et niveaux
- **docs** (Docs) — Analyse documentaire et chat sur vos fichiers
- **emojis** (Emojis) — Module d'affichage d'emojis
- **flashcards** (Flashcards) — Cartes de révision à répétition espacée
- **hello** (Hello) — Module de démonstration (ping backend + composant généré)
- **history** (Historique) — Historique des conversations et recherche sémantique
- **kholle** (Kholle) — Kholles interactives type prépa scientifique (MPSI/MP)
- **minecraft** (Minecraft) — Mini-jeu 2D inspiré de Minecraft avec génération procédurale et aide crafting par IA
- **minuteur** (Minuteur) — Module minuteur simple avec démarrage, pause et réinitialisation, et mode Pomodoro
- **pong** (Pong) — Module de jeu Pong
- **rangement** (Rangement) — sans description
- **settings** (Réglages) — Profil, préférences et personnalisation de l'instance
- **snake** (Snake) — Jeu Snake jouable au clavier ou à la souris, avec accélération progressive et meilleur score.
- **vroom** (Vroom) — Module de course 2D avec véhicules et pistes revisité
