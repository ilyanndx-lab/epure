# Modules existants dans cette instance Épure

- **admin** (Admin) — Organisation et classement automatique des fiches PDF
- **chat** (Chat) — Conversation multi-modèles avec orchestration et recherche web
- **hello** (Hello) — Module de démonstration (ping backend + composant généré)
- **history** (Historique) — Historique des conversations et recherche sémantique
- **settings** (Réglages) — Profil, préférences et personnalisation de l'instance
